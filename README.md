# DBMS Core Notes

A single-page revision guide for database management systems, covering data models, SQL, normalization, transactions, indexing, query processing, security, and distributed databases.

![DBMS Core Notes screenshot](screenshot.png)

## Features

- Topic-based notes for DBMS fundamentals and practical query thinking
- Coverage of ER and relational models, SQL, joins, constraints, and normalization
- Notes on transactions, concurrency, indexing, storage, optimization, NoSQL, and recovery
- Lazy-loaded topic pages with responsive fixed study navigation
- Persistent dark and light themes with a scroll-aware go-to-top control

## Tech stack

React, Vite, React Router, styled-components, React Icons, and CSS.

## Run locally

Run npm install, then npm run dev. Use npm run build to create a production build and npm run deploy to publish it to GitHub Pages.
